# AnimatedWebs Design Studio

1. Call `get_design_workspace`. It returns the user's private workspace link, today's AI usage and a one-line setup for the AnimatedWebs Design MCP server for Claude Code, Cursor and VS Code.
2. Offer to run the Claude Code setup command it returns so Design tools become available in this session. The token in it is personal: never commit it or paste it into shared files.
3. Free accounts include a daily AI allowance; when it runs out, the user can upgrade or add their own API key in Design Studio settings.
